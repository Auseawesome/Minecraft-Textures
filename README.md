# Minecraft Textures
 
This is a repository of free to use minecraft textures I made inspired by [Malcolm Riley's](https://github.com/malcolmriley/unused-textures).

The vast majority of these will be 16x16 sprites (most of which should be indexed) but there may be a random jumble in here of other things as well.

## Licensing

These textures are all licensed under CC0 meaning you can use them for *anything*. Attribution is appreciated but not required, a small notice in the source or adding me to the contributors list of your mod would be more than enough ([My Curseforge Profile](https://www.curseforge.com/members/auseawesome), [My Modrinth Profile](https://modrinth.com/user/Auseawesome)).

## Contributions

Contributions are more than welcome, especially if you want to add some variations of existing texture! I highly recommend other artists with many textures to make their own repositories similar to this one so they can license it however they please. If you would like a link to your texture repo on this one, message me as detailed below.

I do have to stipulate that every contribution is made under the license for this repository however, and I cannot accept contributions under licenses except CC0 due to this.

If after this you do still want to contribute, either contact me or open a pull request!
